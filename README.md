# Система согласования документов

Консольное приложение для управления процессом согласования документов
с базовым набором CRUD-операций и хранением данных в JSON.

## Назначение

Приложение управляет процессом согласования документов в организации.
Для каждой сущности (документ, пользователь, согласование) реализован
стандартный набор операций: создание, поиск, обновление, удаление,
вывод списка.

## Целевая аудитория

Сотрудники организаций: авторы документов, руководители-согласующие,
администраторы документооборота.

## Предметная область

Электронный документооборот: документы, авторы, согласующие, решения и
комментарии.

Правила предметной области:
- автор документа не может согласовать собственный документ;
- на один документ — не более одного активного согласования.

## Основные сущности

### `Document` — документ

Атрибуты: `id`, `title`, `doc_type`, `author_id`, `deadline`.
Методы: `__init__`, `__str__`, `from_data` (`@classmethod`),
`to_dict`.

### `User` — пользователь

Атрибуты: `id`, `name`, `department`, `role`, `email`.
Методы: `__init__`, `__str__`, `from_data` (`@classmethod`),
`to_dict`.

### `Approval` — согласование

Атрибуты: `id`, `document_id`, `user_id`, `decision`, `comment`,
`approval_date`, `is_cancelled`.
Методы: `__init__`, `__str__`, `from_data` (`@classmethod`),
`to_dict`.

## Основные операции (CRUD)

Для каждой сущности реализованы:
- `add_*()` — создание (Create);
- `find_*()` — поиск по идентификатору (Read);
- `update_*()` — обновление (Update);
- `delete_*()` — удаление (Delete);
- `show_*()` — вывод списка.

Для согласования при создании дополнительно проверяются правила
предметной области.

## Хранение данных

Данные приложения хранятся в каталоге `data/`:
- `data/documents.json` — документы;
- `data/users.json` — пользователи;
- `data/approvals.json` — согласования.

При загрузке данные JSON преобразуются в объекты классов через
`@classmethod from_data()`. При сохранении объекты преобразуются
обратно в JSON через `to_dict()`.

## Назначение модулей

- `main.py` — точка входа, меню из 15 пунктов (CRUD для каждой
  сущности + выход);
- `models/documents.py` — класс `Document` и CRUD-функции;
- `models/users.py` — класс `User` и CRUD-функции;
- `models/approvals.py` — класс `Approval` и CRUD-функции с проверкой
  правил предметной области;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод чисел, дат и строк;
- `tests/` — автоматизированные тесты pytest (30 тестов).

## Требования
