# Система согласования документов

## Назначение

Приложение для управления процессом согласования документов: система
проверяет данные документа, контролирует срок согласования, проверяет
возможность согласования и позволяет вынести решение.

## Целевая аудитория

Сотрудники организаций: авторы документов (юристы, бухгалтеры, менеджеры),
руководители-согласующие, администраторы документооборота.

## Предметная область

Электронный документооборот: документы, авторы, согласующие, статусы,
сроки согласования, решения и комментарии.

## Основные сущности

1. **Документ** — название, тип, статус, срок согласования.
2. **Автор** — ФИО, подразделение, должность.
3. **Согласование** — согласующий, решение, дата.
4. **Комментарий** — автор, текст, дата.

## Основные функции

1. Проверка заполнения основных данных документа.
2. Проверка срока согласования документа.
3. Проверка правила «автор не может согласовать свой документ».
4. Вынесение решения о согласовании или отклонении документа.
5. Определение и вывод текущего статуса документа.

## План развития

- Разработка веб-приложения на Django;
- Подключение базы данных;
- Реализация пользователей, регистрации и авторизации;
- Разработка REST API;
- Контейнеризация приложения;
