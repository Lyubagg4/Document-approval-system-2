# Система согласования документов

Консольное приложение для управления процессом согласования документов:
система проверяет данные документа, контролирует срок согласования,
проверяет возможность согласования и позволяет вынести решение.

## Назначение

Приложение управляет процессом согласования документов в организации.

## Целевая аудитория

Сотрудники организаций: авторы документов, руководители-согласующие,
администраторы документооборота.

## Предметная область

Электронный документооборот: документы, авторы, согласующие, статусы,
сроки согласования, решения и комментарии.

## Основные сущности

1. **Документ** — название, тип, автор, срок согласования, статус.
2. **Пользователь** — ФИО, подразделение, должность, email.
3. **Согласование** — документ, согласующий, решение, дата, признак
   отмены.

## Возможности

- добавление, поиск и сортировка документов;
- проверка срока согласования документа;
- добавление и поиск пользователей;
- проверка возможности согласования (правила автора и дубля);
- создание и отмена согласований;
- определение текущего статуса документа;
- сохранение данных в JSON между запусками.

## Требования

- Python 3.10+;
- pytest >= 8.0;
- flake8 >= 7.0.

Установка зависимостей:

```bash
pip install -r requirements.txt
```
